# Announcement thread for 0.8.0

## 1/

Today I shipped twelve changes to chantier through chantier itself. I talked to one
agent, the Chief of Staff. It gave each change to a Driver, brought me each pull request with
its checks green, and when I wrote "87 merged" it cleaned up and asked the next Driver to rebase.

chantier 0.8 makes that easier to start and to stop. The Chief of Staff can now steer a batch
itself, in the conversation you are already in, so it works from a terminal or an IDE and not
only from the desktop app. When the work is done the batch pauses and shows what it cost so far.
It closes only when you say so. The board also shows how many Drivers can still start.
