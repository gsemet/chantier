# Announcement thread for 0.14.0

## 1/

I used to give a go for each change I wanted in a batch. Now I open one batch with nothing in it, keep specifying, and each change I make ready joins it on its own; I also set the batch's slots from the board, and the session hears about it without me typing. That is chantier 0.14, plus one server per project that runs the board and reads the forge.

No eval campaign ran for it: the notes say which changes no run has seen, and that the server's election has not run on Windows yet.
