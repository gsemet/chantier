# Announcement thread for 0.12.0

## 1/

When I wanted to know where a batch stood, I used to read a list of changes and guess the timing. Now the board's Batch page has three tabs: the graph, a Gantt with one bar per change, and paper time cards with each round and its verdict. Every card and column of the board follows one written design, and each PR, MR or issue opens on its forge from where you see it.

chantier 0.12 also keeps a batch tidy at its end. No eval campaign ran for this release: the notes say which changes no run has seen.
