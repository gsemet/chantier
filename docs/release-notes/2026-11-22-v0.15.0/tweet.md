# Announcement thread for 0.15.0

## 1/

I used to look in three places to know what chantier waited on me for: the session, the forge and the planning folder. Now the web board has an Inbox of what needs me, a History of what was done and a Dashboard of what it cost, and the server behind it reads the forge only for what a running batch awaits. I can also log in from another machine and run chantier commands there through that server. That is chantier 0.15.

No `full` or direct-mode eval ran for it: the notes say which changes no run has seen.
