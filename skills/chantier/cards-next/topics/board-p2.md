# The board (part 2 of 2)

- A board another session serves is the user's to stop. Never start one on another port to get round it: on the user's word run `serve --seat <id>` again, or `serve --restart --seat <id>`. A board started by hand runs in the background, never the foreground. Start lines: `help board-lines`. A newer build: `help board-restart`.
- A `--forge-always` board you started stops when the seat moves and reads the forge with or without a client, so the pull path still prints its `forge saw merged` lines.
