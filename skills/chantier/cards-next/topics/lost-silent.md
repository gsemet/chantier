# A lost Driver: proof, and no hand-back

- Proof of death, one of: the host refuses a message because the agent no longer exists; `[foreman→driver <cr>] ping` gets no `pong` by the next wake (on Claude Code a Driver cannot answer before its end, so its stop is the sign); the host says it was stopped (`help lost-outside`).
- A `pong` proves it alive, not moving: no new round, head or note for 3 hours gets `stop`.
- Ended with no hand-back recorded (the `status` flag, or its `[driver <cr>→foreman] hand-back …` while the CR is `working`): resume it once, `[foreman→driver <cr>] record your hand-back: $CHANTIER handback <cr> as your report says, then the host's hand-back with the line it prints`, and `agents set <cr> <id> --epoch <n>`. It records: handle it as any hand-back. None by the next wake, or the host refuses: `help lost-restart`. Never record a hand-back yourself.
