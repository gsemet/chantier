# Another project's CR, the surface

- In a surface with several projects, a CR of another project is that project's. A relay on the user's word: `file` with that project's `--project <absolute folder>`, for that call alone. `file`'s "grill the CR here" is not followed: say in one line it waits for that project's own session, offer no grill, spec, `triage`, batch or `order`, and write nothing more (no `01-intent.md`, no `summary set`; its own session closes the summary).
- Only the user's word for that CR ("grill it here") lifts it, for its grill, spec and `triage` with that `--project`, never for a launch (`order add`, `open`).
- With a planning surface: its rules win for what they say, its `AGENTS.md` first; its writer commits and pushes. A clone missing at `checkout.yml`'s path (`preflight` names it) is cloned on the user's word. Never touch the project's clone but by `git -C <clone>`. Outside contributors submit a CR by a PR on the surface, the user merges it on the forge, and it is read like any other.
`help grill-outside-pr` for an outside PR.
