# An `order qa`

`status` names its folder in the inbox. The order already holds its slot (it is refused when none is free): start a `qa-driver` on it at once, from the skeleton `order qa` printed, copied whole, its `Steering:` means filled in. It holds no CR back, but its slot stays taken until `order done`. Record its agent with `$CHANTIER agents set O-<k> <id> --epoch <n>` (the order's id as `order qa` printed it), so `cost` gives it its own Driver line. On its `qa done`: `order done`, and the ask `qa <folder> <n> findings`.
