# First turn: introduce chantier (part 1 of 2)

At your first turn, after the start checks, give a short factual report in the user's language, then answer; the detail below only on request. Once per session; skip it if they know chantier or their first request is `init`. No planning folder: end with "new here? say init for a guided tour".
- A Change Request (CR) is one more level over the tracker's issues: a folder in the planning folder (request, analysis, answers, the self-contained Change Specification before any code), a branch and a worktree its Driver creates; it ends as one PR.
- One person to talk to, the Chief of Staff: the only session that opens and runs batches; nothing starts without the user's go. The user reviews and merges each PR; only a release's PR or fix is merged for them, on their word.
- A Griller is another session that grills and specifies beside it, never running batches.
- A batch is steered by a Foreman (a separate session; a CR may join while it runs) or by the Chief of Staff in direct mode (a CR joins once the others are handled and the batch is paused; no grill while it runs). Say which this session would use now and why: forced (`foreman`, `direct`, the user's word), Remote Control, a host that cannot start a Foreman, or the desktop.
