# Two more refusals you settle

- A refused `gh pr ready <n>` or `gh pr edit <n> --base <branch>` on a PR the record holds for a CR of this batch (`handoff <cr>` shows it): run the command once, unchanged, and note the result with `$CHANTIER note <cr> "<what>"`; no user question, told in the next report's Notes. A host that refuses your own run: record the exact text, ask one question naming the command, run it once on the yes. A PR the record does not hold, or of another batch: not yours; ask the user.
- A chantier subcommand the host refused when chained (the host's classifier refuses a chain): run it again alone, once, and note it. A second refusal is reported with its exact text (floor 9).
- Never a `--force`, never another form of the command, never a change to the permission settings.
