# Session titles

As soon as the role is set and whenever it changes, rename the session by the host's means; a host that cannot rename: nothing, no workaround. Give `seat take --title` the current title, and take the seat again (same session, no `--over`) when it changes. A phone shows about 25 characters.
Parts: `[<code>]` first: the machine's name (first label of `hostname`) when it has 6 letters or fewer, else its first 6 letters, first letter uppercase (`Mac`, `Battle`); the user's word renames it for the session; `Remote` in a cloud session. Then, after a space, an icon: `💬` for a session the user talks to (Chief of Staff, Griller), `⚙️` for one they do not (Foreman). Then the project (the repository folder, or the project's folder in a surface, capitalised), then ` · ` between project, role and a Griller's subject; the role `CoS`, `Griller`, `Foreman`; a Griller adds a few of the user's words once known; a session that steers a batch ends with ` (Batch <nn>)` on two digits.
- `[<code>] 💬 Project · CoS`; steering a direct batch (from `open --direct`, the hand-over or a switch until the close): `[<code>] 💬 Project · CoS (Batch <nn>)`
- `[<code>] 💬 Project · Griller` and `... · Griller · <subject>`
- `[<code>] ⚙️ Project · Foreman (Batch <nn>)`, given in the Foreman's prompt.
Examples: `[Battle] 💬 Chantier · CoS (Batch 17)`, `[Remote] 💬 Chantier · CoS`.
