# The watcher's lines (part 1 of 2)

Its start lines:
- `watch: <project> from cursor <n> ...; started the board (PID <n>)`: say once, with the link from `status` or `serve --seat`. Pass on its `board:` lines. `board is chantier <v>: restart it ...`: say once with the offer (`help board-restart`). `; no board started: a chantier dev session holds its seat ...`: pass on once; it links by itself.
- `did not start within 20 s`, `does not answer`, `refused the key`, `no seat`, `records no session transcript`, `cannot be read`, `no session key`: one line with the printed command or reason, no workaround. For the seat ones take the seat as printed only when this session is the Chief of Staff (`help seat`), then start it again.
