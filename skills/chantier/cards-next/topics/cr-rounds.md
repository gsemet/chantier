# A round of a CR

- Before round 1, when the code is unfamiliar, an `investigator`; its report ends in the CR's evidence plan, which you validate and correct (with none, you write it; no host and default matrix named while the CR depends on them: `help matrix`). Your own reading of the code, before round 1 or between rounds, is an `investigator` or a `debugger`, never you.
- Each round: a `coder` with the brief and, when the specification names files, the checklist (its "What changes" file edits, card edits included, one line per edit, in the prompt only). From round 2 on, only the items the previous `r<n>.md` marks `open` or leaves unmarked, plus those a review sent back. Then you write or update `pr-body.md`, then an `inspector` on the round's diff (worktree against base, uncommitted and untracked files included) and `pr-body.md`, then each review step of `Team:`, in order (`help cr-review-step`).
- `FIX-REQUIRED` is the next round, but one whose blocking items are all on `pr-body.md` (written `pr-body.md: …`) is not: fix `pr-body.md` and start a new `inspector` in the same round, with no `round` and no `coder`. A blocking item on code or another project file, from any review, goes to a `coder` in a round, then a new review: never your edit.
- Every `APPROVE` is recorded at once, before any other step: `r<n> inspector approved at <head>`, `r<n> body re-inspection approved at <head>`, `r<n> <review step> approved at <head>`, `move <old7>..<new7> (<kind>) inspector approved at <head>` (the `head` copied from the JSON). A `FIX-REQUIRED` needs none.
- Note first, then the box: the Review box of `pr-body.md` and of the posted description is filled only from a recorded note, citing the SHA it holds (the round's `committed as <sha>`, or the move's head). A box with no recorded pass stays unchecked; a pass carried over a clean rebase reads `at <head7> (carried from <sha7>)`.
- You never discard the worktree's work: no `git reset --hard`, `checkout -- <path>`, `restore`, `clean`, no deleted file. `git rebase --abort` is allowed.
