# The retro critic: the section and the verdicts

- Write the section with the kept points only, each as drafted (a merge: one line covering both; a kept release point is marked `(release)`), under the same header, ending `(critic: kept <k>, dropped <d>)`. Every point dropped: one untagged line `- nothing worth changing (critic: <d> points dropped)`.
- Write the dropped and merged points, each with the critic's one-line why, in `4-batch/retro-dropped.md` (a section per pause, headed like the retro's; `close` deletes it).
- Follow the verdicts as given: never keep a dropped point nor drop a kept one.
