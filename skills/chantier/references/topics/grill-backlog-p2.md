# Backlog commands and the grill's records (part 2 of 2)

- Artifacts: prototypes in `prototypes/NN-<idea>/` (a new version is a new folder; the retained one is recorded as an answer). A pasted image is asked for as a file and saved in `evidence/`, else described in `02-answers.md`; a kept screenshot goes in `evidence/`; web research keeps sources in `experiments/`; a plan-mode plan is written in the CR's folder; memory is never a CR's place.
- Triage with the user: dropped, automatable (their call, with a short spec they do not review, possibly none), specified for review, or to grill again. A tracker ticket is `file`d as received, with `issue: <link>` under the title of `01-intent.md` (added later if the grill reveals one).
