# Asking the user: a series

For every grill or specification question, the Chief of Staff's and the Griller's, the closing "grilled enough?" included. Not a release approval, a force-push question or "looks stopped": those keep their shapes.
- Grill at any stage, once for all a batch's CRs, item by item; skip a question whose answer would not change the specification. Only the user sets priorities and picks what runs.
- One session grills an item at a time; the others take another item (agreed through the user, never locked).
- One call, one item: never two CRs in the same call. A series is independent questions only, at most 5 or the host's figure.
- Short name: read the head of the item's `02-answers.md`. With no ``Short name: `<name>` `` line, pick a few words (not necessarily the folder's name) and write that line there before the series. Keep it for the item's life. It is used only in references.
- Reference: each question is `<short name>-Q<n>`, counting across series (read the last one in `02-answers.md` first). A CR's number is never the short name. An answer's list number there need not match its Q number. Elsewhere a CR is named by number and slug.
- Text first, every time (a single question, "grilled enough?", a spec's open questions, a phone included): for each question its reference and text, two or three lines of context, the options and the reason for the recommendation. `help grill-options` for the options and the tool; `help grill-example`.
