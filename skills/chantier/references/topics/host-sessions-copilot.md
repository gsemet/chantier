# Copilot: sessions

The Foreman is started by `create_session`; a refused start is reported with its exact text.
Nothing else about Copilot's sessions is recorded (unproved): its surfaces and its Remote Control
signal are not known, so offer every option with its condition, and the no-argument mode follows P1
and P2 only. A Driver stopped from outside is unproved: the lost-Driver rule holds when the host
says it was stopped (`help lost-outside`). The seat's session always "looks stopped" to a new
session: ask the "looks stopped" line.
