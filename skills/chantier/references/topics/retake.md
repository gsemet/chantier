# A CR that comes back

- A first `take` that shows a `PR:` link: use the branch and worktree `take` printed, never a new branch. Read the PR first (`gh pr view <n> --json state`, `glab mr view <n>`): open, go on; closed, `gh pr reopen <n>` / `glab mr reopen <n>` before any push, refused: `handback <cr> blocked question: its PR <link> is closed and the forge refuses to reopen it: <exact text>`; merged: `handback <cr> blocked question: its PR <link> is already merged`. Rebase on the base `take` names, ship to that PR: never a second PR.
- `rebase: <cr> merged` with no open dependency or predecessor left (or no dependency at all, in a parallel batch): fetch, rebase onto `origin/<default branch>` (a conflict that needs only resolving: `conflict-resolver`; one that needs code is a round), retarget the PR to the default branch if it was elsewhere (`gh pr edit --base`, `glab mr update --target-branch`), push (`help refused-push`), `ship`, read CI (red is a round).
- A clean rebase: no long gate, no `verifier`; the pass and verdict carry (`carried:`). Mark each proof in `pr-body.md` whose SHA left the head's history (Test plan items, `Verified at` box, evidence captions) `at <new head7> (carried from <sha7>)`, as `ship`'s `off: pr-body.md line <n> names …` lines guide, attach the image files `ship` names, run the pre-post audit and post the file.
- With a conflict resolved: the early push (`help conflicts-early-push`), `ship --conflict`; the `verifier`, given the move, judges again what it touched.
- Green, no conflict, on the default branch: turn the PR ready and `handback ready <link>`. If the note names another open dependency, or is `rebase: <cr> moved`, or `take` prints the base as another CR's branch: rebase onto it, keep the PR draft, `handback ready <link> draft on <base>: waits for <cr>`.
- A CR taken back `blocked` for a rebase is handed back blocked with the reason it had.
- A `note rebase: …` received while working: one rebase before the next push, however many came, onto the latest default branch; stop your running long gate (`gate <cr> --stop`) first. `rebase: stacked on <cr below>, without <dropped cr>` changes the command only: `git -C <worktree> rebase --onto <base> <the dropped CR's branch>`.
- Stack and series bases: `help retake-stack`. Other notes: `help retake-notes`.
