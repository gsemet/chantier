# The "For you" block: a reused Foreman, a new session

Same four parts as `help host-for-you`.

- **A reused Foreman**: cost, its context is carried. In its session type `/compact` and wait; I
  send the prompt by message; if the session is closed (unproved that a message wakes it), paste
  the prompt into it (desktop app, the session in the list, click its input, paste); See:
  `ready <batch>` within a few minutes.
- **A session on the main checkout**: cost, a fresh context (the files hold the state; nothing is
  lost once the start check found the worktree clean with no commit). In the desktop app or remote
  client, start a new session on the repository's folder with Worktree off (documented:
  <https://code.claude.com/docs/en/desktop>); Paste `/chantier:chief-of-staff` or
  `/chantier:griller`; See: the introduction with no start-check failure, else say what it shows.
