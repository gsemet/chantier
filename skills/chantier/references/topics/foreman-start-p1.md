With no folder it opens paused with no CR (`--release` refused then; CRs join with `order add --note <folder> --batch <batch>`, each planned as a CR joining a paused batch is; the first `take` sets it running). It moves each folder to `4-batch/1-pending/`, names branches and worktrees and writes `brief.md`: complete it from the grill (the team, autonomous decisions allowed, questions to bring back). Right after `open`, before the first `take` or the Foreman, record each wait the go approved: `order after <cr> --note "<cr>"` then `order note <cr> --note "chain: <reason>"` (`--add` adds one, `--note` replaces the list; no `--epoch`).
