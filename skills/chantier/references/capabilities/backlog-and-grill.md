# Capability: backlog and grill

## Purpose

Keep the backlog and ask only the questions that change the result.

## Who uses it

Chief of Staff.

## Commands

Backlog layout, priorities P1–P4 and filing rules are change-request-factory's:
[../../../change-request-factory/references/backlog.md](../../../change-request-factory/references/backlog.md).

## Rules

- File an item from the user's words and evidence; never invent scope.
- Grill once for the whole batch. Each question carries a recommended answer; skip questions
  whose answer would not change the brief.
- A decision taken without the user goes into the brief as an autonomous decision, and later
  into the PR body.
- Never start a backlog item on your own.

## Failure handling

The user does not answer a blocking question: the CR stays out of the batch; say so.
