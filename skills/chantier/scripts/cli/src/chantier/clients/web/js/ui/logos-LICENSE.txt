The provider marks in logos.js are copied from Lobe Icons.

Source: https://github.com/lobehub/lobe-icons, as the npm package @lobehub/icons-static-svg,
version 1.103.0 (files icons/<name>.svg). Licence: MIT (below).

The variant taken for each mark:
  anthropic  claude-color.svg   the coloured Claude mark (one fill, tokenised as --logo-anthropic)
  openai     openai.svg         the mono OpenAI mark, drawn in the text colour (currentColor)
  google     gemini-color.svg   the coloured Gemini mark (one fill and three gradients, tokenised
                                as --logo-google-*)
  xai        grok.svg           the mono Grok mark, drawn in the text colour (currentColor)

Changes made to the markup: the `style`, `height`, `width` and `xmlns` attributes and the
`<title>` are dropped (the board sizes a mark in CSS); each colour is a `var(--logo-...)` token
of css/tokens.css; a gradient's id gets a counter suffix so that one page can draw a mark twice.

The marks are the trademarks of their owners (Anthropic, OpenAI, Google, xAI). They are shown
only to name the provider of a model; their licence does not cover the trademarks.
