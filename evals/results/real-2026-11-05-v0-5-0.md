## Findings

1. **No Inspector sent work back, for the second run.** That makes seven CRs without a returned
   verdict. These two were small, so this says little either way. An eval with planted defects
   would tell.
2. **The QA driver kept no proof.** `evidence/` holds only a README: the output of its commands was
   not saved, so its findings cannot be checked from the folder. The card should ask for that
   output.
3. **`file` on an existing slug exits 3, which `concepts.md` gives to a stale Foreman epoch.**
   Checked in the code: the error uses `EXIT_CONFLICT`. An agent reading the code would take it for
   the wrong failure. Fix the code or the card.
4. **QA reported eight more points on the CLI, not checked here.** They are in the inbox folder, to
   triage with the user: `triage` cannot change a backlog CR's priority, a second `order drop` runs
   again and reports success, orders the CLI already applied stay pending, `cost` fails on a batch
   with no Foreman, and several unclear messages.
5. **The Foreman is the largest cost, at 44%.** The reused session carries the context of earlier
   batches, so this run overstates it. A new session per batch remains the runbook's advice.
